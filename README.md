# پروژه مدیریت اسناد

این پروژه یک سیستم مدیریت اسناد است که با **Spring Boot** توسعه یافته است.  
با استفاده از این پروژه می‌توانید اسناد را ثبت و مدیریت کرده و با چهار حالت مختلف جستجو کنید.

## ویژگی‌ها
- ثبت سند جدید با جزئیات کامل
- جستجوی سند با چهار حالت:
  1. جستجو بر اساس عنوان
  2. جستجو بر اساس محتوای سند
  3. جستجو بر اساس برچسب سند
  4. جستجو بر اساس تمام موارد
- رابط کاربری ساده و REST API برای عملیات‌ها

  ##دسترسی به api ها از طریق:
   
http://localhost:8080

ساختار پروژه

/src/main/java : کدهای اصلی پروژه

/src/main/resources : فایل‌های پیکربندی و منابع

/src/test/java : تست‌های واحد

README.md : مستندات پروژه


مثال استفاده:
ثبت سند جدید:
POST /documents
{
  "title": "گزارش مالی",
  "content": "گزارش مالی سال 1404",
  "tags": ["finance"]
}

جستجو در اسناد:
GET /documents/search?query=گزارش مالی&mode=TITLE
